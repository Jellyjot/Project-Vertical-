🛰 CONNECT TO MISSION CONTROL (SUPABASE)

Go to supabase.com, sign up free, and create a new project. Name it anything (e.g. project-vertical). Wait ~2 mins for it to spin up.
In your project, go to SQL Editor (left sidebar) and run this query to create the data table:
CREATE TABLE sprint_data ( id TEXT PRIMARY KEY DEFAULT 'main', data JSONB NOT NULL, updated_at TIMESTAMPTZ DEFAULT NOW() ); INSERT INTO sprint_data (id, data) VALUES ('main', '[]'::jsonb); -- Allow public read/write (no auth needed) ALTER TABLE sprint_data ENABLE ROW LEVEL SECURITY; CREATE POLICY "Public access" ON sprint_data FOR ALL USING (true) WITH CHECK (true);
Go to Project Settings → API (left sidebar). Copy your Project URL and anon public key, and paste them below.
Paste your credentials below and click Connect. This is saved in your browser — your team just needs the URL, no setup required on their end.
